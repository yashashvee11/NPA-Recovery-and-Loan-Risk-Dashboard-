# 📊 NPA Recovery and Loan Risk Dashboard

This project is a data visualization dashboard designed to analyze and monitor Non-Performing Assets (NPAs) in the banking sector. Built using Tableau, the dashboard provides critical insights into loan defaults, recovery performance, high-risk borrowers, and asset quality across branches, loan types, and borrower segments.

---

## 📌 Key Objectives

- Identify top defaulters based on overdue and write-off amounts.
- Analyze provisioning against asset categories.
- Visualize distribution of NPAs by industry and region.
- Highlight branches with strong and weak recovery performance.
- Assess high-risk borrowers using credit scores and overdue loan amounts.
- Conduct aging analysis of loans across branches.
- Monitor overall loan health by category and loan type.

---

## 📊 Visualizations Included

| Feature                | Chart Type       | Description |
|------------------------|------------------|-------------|
| Top Defaulters - Overdue | Bar Chart        | Displays borrowers with the highest overdue amounts. |
| Top Defaulters - Write-Off | Bar Chart     | Shows borrowers with significant write-off amounts. |
| Provisioning vs Asset Category | Stacked Bar | Compares provisioning amount across asset categories. |
| NPA Distribution       | Pie Chart / TreeMap | Shows % of NPAs across industries and regions. |
| Risk Profile           | Scatter Plot     | Plots loan amount vs credit score, highlighting risky accounts. |
| Aging Analysis         | Stacked Bar Chart | Compares SMA-0, SMA-1, SMA-2, and NPA stages across branches. |
| Branch Performance     | Map / Bar Chart  | Identifies branches with best and worst recovery performance. |
| High Risk Heatmap      | Heatmap          | Displays borrowers with high overdue and low credit score, categorized by loan type. |

---

## 🛠️ Tools Used

_ **Pandas**: For Data Cleaning and EDA
- **Tableau**: For interactive visualizations and dashboard creation.
- **Excel / CSV**: For preprocessing and cleaning raw borrower and loan data.
